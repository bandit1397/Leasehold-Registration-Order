## Word로 고치는 방법 (한글 프로그램이 없을 때)

1. `서류/Word/`의 .docx 파일을 더블클릭해 Word로 연다.
2. 노란 형광펜으로 표시된 빈칸(000)을 실제 내용으로 바꾼다. 금액(5,000,000원 등)은 형광펜 대상이 아니다.
3. 다 고친 뒤 **형광펜을 지운다**: Ctrl+A → 홈 → 형광펜 ▼ → 색 없음. (지우지 않으면 노란색이 인쇄됨)
4. 파일 → 다른 이름으로 저장 → 형식 PDF 로 제출용 PDF를 만든다.
5. Word에서 고친 내용은 HWP·PDF 폴더 파일에는 반영되지 않는다. **이후로는 Word 파일을 원본으로** 삼는다.
6. HWP가 꼭 필요하면 무료 웹 서비스 한컴독스(hancomdocs.com)로 열거나 변환할 수 있다(직접 시험해 보지는 않음). 전자소송은 PDF 제출이 가능하다.

### 사전 고지: 임차권등기 신청을 집주인에게 미리 알릴 의무는 없다
- 주택임대차보호법·규칙 어디에도 사전 통지 요건이 없다. 신청은 임차인이 법원에 혼자 하는 절차이고, 법원이 결정을 임대인에게 송달한다.
- 2023년 개정으로 결정이 임대인에게 **송달되기 전에도 등기 촉탁**이 가능해져, 집주인이 등기 사실을 먼저 알게 되기 어렵다.
- 내용증명은 신청의 요건이 아니다. 보내는 이유는 ① 반환 청구 기록 ② 동시 인도 제공(임대인을 지체에 빠뜨림) ③ 증거(갑 제12호증)이다.
- 그래서 내용증명에서는 "임차권등기" 문구를 빼고, 일반적인 권리 유보만 남겼다.
- 등기 결정 뒤 집주인은 이의신청을 할 수 있으므로, 해지 문자·평면도·내용증명 사본은 보관한다.
| 6 | 2026타경○○ 배당요구 사실 | 경매절차에서의 권리 행사 고지 |

### 11. 5. 동시 인도 약속에 따르는 주의
- 임대인이 11. 5.까지 **전액(또는 관리비만 정산한 금액)을 주면 그날 열쇠를 넘기고 집을 비워야 한다.** 11. 5.까지 짐을 뺄 준비를 해 둘 것.
- 반환을 받으면 임차권등기는 필요 없어지므로, 결정 전이면 **신청 취하**, 등기가 끝났으면 **말소에 협력**한다(이미 낸 인지·송달료 등은 임대인에게 청구 가능). 내용증명에는 쓰지 않았지만 실제로는 이렇게 처리한다.
- 일부만 주거나 관리비 외의 금액(원상복구비 등)을 많이 빼려 하면, 그 금액에 동의하지 말고 인도를 보류할 수 있다. 다툼 없는 금액이 들어오기 전에는 열쇠를 넘기지 말 것.
- 반환받기 전에 먼저 이사하면 안 된다. 임차권등기가 기입되기 전 전출은 대항력 상실.

### 건물 매도 가능성에 대한 검토
- (내용증명에는 매도·승계 이야기를 쓰지 않음 — 알리지 않아도 법적 효과는 같다.)
- **지금 살면서 전입을 유지하는 한 매도는 크게 위험하지 않다.** 2026. 2. 23.부터 대항력이 있으므로 매수인이 임대인 지위를 자동 승계해 보증금 반환 의무를 진다(주택임대차보호법 제3조 제4항). 위험한 것은 **이사(전출)한 뒤에 매도되는 경우**이고, 이를 막는 것이 임차권등기다.
- **임차권등기 기입 전에 소유권이 넘어가면** △△△를 상대로 한 등기명령은 등기부상 소유자와 달라 등기가 되지 않을 수 있다. 그 경우 임대인 지위를 승계한 **새 소유자를 상대로 다시 신청**한다. 그때까지 이사하지 않으면 권리는 그대로 유지된다.
- 빠르게 하는 방법: 11. 3. 오전 전자소송 접수, 신청서·보충서에 "건물 매도 가능성이 있어 신속한 결정을 바란다"는 사정을 덧붙이고 법원에 전화로 확인, 등기부를 자주 열람(인터넷등기소)해 소유자 변동 확인.
- 이미 경매(2026타경○○)가 진행 중이라 압류 이후의 매도는 경매에 영향을 주지 못한다. 경매로 팔리면 낙찰자에게는 2017년 근저당 때문에 대항할 수 없으므로 **배당요구가 핵심**이다.

| 요건 (주택임대차보호법 제3조의3 제1항) | 판단 |
|---|---|
| 임대차 종료 | 충족 — 임대인의 "10. 30.까지 미납 시 해지" 통지는 조건부 해지로 유효하고, 기한 경과로 10. 31. 종료 |
| 보증금 미반환 | 충족 — 0원 반환, 연체 차임 공제 후에도 잔액 존재 |
| 해지 사유(민법 제640조) | 충족 — 연체 차임 920,000원 ≥ 2기 차임 460,000원 |

### 주의할 점
1. **2기 연체 시점 확인** — 해지 통지(10. 26.) 당시 이미 2기(460,000원) 이상 연체였어야 한다. 미납 시작 월(현재 000)을 확인해 신청서·정산서에 채울 것.
2. **종료 후 거주 기간의 차임 상당액** — 보증금 반환과 동시이행으로 계속 거주할 수는 있지만, 실제로 사용하면 11월 이후 월 230,000원 상당이 부당이득으로 보증금에서 공제될 수 있다(반환 잔액이 매달 줄어듦). 임차권등기 완료 후 빨리 이사하는 것이 유리.
3. **이사 시점** — 반드시 등기부에 임차권등기가 기입된 것을 확인한 뒤 이사·전출. 2023년 법 개정으로 임대인에게 결정이 송달되기 전에도 등기 촉탁이 가능해졌지만, 기입 확인 전 전출은 금지.
4. **경매와의 관계** — 대항력·우선변제권은 2026. 2. 23. 취득해 2026. 4. 경매개시결정보다 앞서므로 배당받을 자격이 있다. 임차권등기 자체는 낙찰자에게 인수되지 않으며, 이사 후에도 배당 자격을 유지하게 해 주는 것이 핵심 효과. 배당요구는 철회 금지.
5. **최우선변제** — 원주시는 "그 밖의 지역", 보증금 500만 원은 어느 시기 기준으로도 소액임차인. 기준은 2017년 근저당 설정 당시 시행령이므로 설정일(000)을 확인해 배당 때 주장.
6. **임대인 이의신청 대비** — 결정 후 임대인이 "해지하지 않았다"거나 "목적물이 다르다"고 다툴 수 있다. 10. 26. 문자 원본, 평면도 202호 표기, 내용증명 사본을 보관. 해지 의사표시는 도달 후 일방적으로 철회할 수 없다.
7. **송달 주소** — 피신청인 주소는 등기부상 주소와 실제 주소를 함께 확인. 송달 불능이면 보정명령이 나온다.
8. **보증금 반환과 말소** — 판례상 보증금 반환이 임차권등기 말소보다 먼저다. 반환받기 전에 말소에 동의하지 말 것.

## 반드시 확인할 사항 (주의)

### 1. 아래층 공부상 203호·204호 위치가 반대로 표시되어 있을 수 있음 — 확인 필요
- 평면도에 인쇄된 작은 글씨: **아래 왼쪽 = "203호~503호", 아래 오른쪽 = "204호~504호"**
- 사진 1(공부상 호실 표시)의 파란 글씨: **왼쪽 204호, 오른쪽 203호** → 도면 글씨와 반대
- 우리 방(빨간색 = 도면 표기 "202호~502호")은 도면 글씨와 일치하므로 **목적물 동일성에는 영향 없음**
- 그러나 법원·임대인이 보면 사진 신빙성을 문제 삼을 수 있어, 별지 2 대응표는 "공부상 203호, 204호 → 현장 204호~207호"로만 적어 둠
- 이 모순 때문에 **보충서의 "공부상 203호 임차인이 현장 205호를 사용" 항목과 갑 제11호증(다른 임차인 등기 기록)은 삭제함** (도면 글씨대로면 공부상 203호는 현장 206·207호 쪽이라 맞지 않음). 202호 동일성은 도면의 "202호~502호" 표기로 충분히 소명됨
- 건축물대장 현황도로 어느 쪽이 맞는지 확인되면 사진 1의 203·204 표시를 맞춰 고칠 것

### 1-1. 신청취지 정리 (최종 검토 반영)
- 신청취지는 결정문·등기부에 그대로 옮겨지므로 **등기 사항만** 남김: 계약일, 보증금·차임, 주민등록일, 점유개시일, 확정일자, 임차범위("나동 제202호 전유부분 전부")
- "현장 203호", "관리비 별도", "임대차 종료일"은 신청취지에서 빼고 신청이유·보충서에만 둠 (등기부에 203호가 적혀 혼동되는 것을 방지)
- 보충서 5항: 경매에 낸 종전 보정서에 **「공부상 제202호 일부」로 적혀 있었음을 그대로 밝히고**, 공부 대조 전에 작성한 것이었으며 대조 결과 전유부분 전체로 정정한다고 확정 문장으로 고침

### 2. 미납액 40,000원 차이
- 처음 파악한 미납 총액 1,200,000원 ≠ 항목별 합계 1,240,000원(차임 230,000×4 = 920,000 + 관리비 80,000×4 = 320,000)
- 해지 효력에는 영향 없음: 차임만으로 920,000원 > 2기 차임액 460,000원
- 월별 내역으로 확정해 신청서·정산서 금액을 맞출 것. 관리비 공제가 인정되지 않으면 반환잔액은 4,080,000원

### 3. 목적물 표시
- 모든 서류에서 "공부상 나동 제202호 전유부분 전체(현장 표시 제203호)"로 통일. "203호"만 쓰거나 "202호 일부"로 쓰지 말 것
- **경매(2026타경○○)에 낸 보정서에 "202호 일부"로 적혀 있었음 → 경매법원에도 "202호 전유부분 전체"로 다시 보정서를 낼 것 (배당기일 전에, 별지 2 비교 사진 첨부). 경매 쪽 표시가 "일부"로 남아 있으면 배당 단계에서 다툼이 생길 수 있음**
- 「일부」·「사선」 표시가 있는 예전 도면은 쓰지 말 것
- 목적물이 전유부분 전체이므로 도면은 법정 필수서류는 아님(일부 임차일 때만 필수). 호실 불일치 소명을 위해 첨부함

### 4. 별지 2 도면·사진
- 치수(가로 3,600mm × 세로 5,700mm)는 사진 속 도면 숫자를 읽은 벽 중심선 기준값. **면적은 반드시 등기부 전유면적을 옮겨 적고**, 도면 치수로 계산하지 말 것
- 사진이라 약간 기울고 작은 글씨가 흐림. 가능하면 정식 발급한 건축물현황도에 같은 빨간 선을 그려 교체
- 사진 속 도면이 설계도면인지 대장과 함께 발급된 현황도인지 사진만으로는 알 수 없음 → 별지 2 "도면 출처"를 확인 후 채울 것

### 5. 임차권등기의 효과와 한계
- **등기부에 임차권등기가 기입된 것을 확인하기 전에는 이사·전출하지 말 것** (먼저 전출하면 종전 대항력이 사라지고 등기 시점부터 새로 시작)
- 2026. 4. 경매개시결정 이후의 임차권등기는 **낙찰자에게 인수되지 않음** → 경매에서는 배당요구가 핵심
- **2026타경○○ 배당요구는 절대 철회하지 말 것**, 배당기일 확인
- 2017년 근저당권보다 앞설 수 없음 → 배당 때 소액임차인 최우선변제(주택임대차보호법 제8조)를 따로 주장
- 등기부상 소유자가 이미 제3자로 바뀌었으면 피신청인과 전략이 달라짐
- 임대인의 이의신청에 대비해 등기 완료 때까지 대화는 문자·녹음으로 남길 것
- 신청 비용은 임대인에게 청구 가능(같은 법 제3조의3 제8항)

### 6. 기타
- 가족이 대신 접수할 때는 위임장(서류 10)과 가족관계증명서를 쓰되, 법원 허가(소송대리허가) 필요 여부를 민사신청과에 먼저 확인
