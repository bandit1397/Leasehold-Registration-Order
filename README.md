## Word로 고치는 방법 (한글 프로그램이 없을 때)

1. `서류/Word/`의 .docx 파일을 더블클릭해 Word로 연다.
2. 노란 형광펜으로 표시된 빈칸(000)을 실제 내용으로 바꾼다. 금액(5,000,000원 등)은 형광펜 대상이 아니다.
3. 다 고친 뒤 **형광펜을 지운다**: Ctrl+A → 홈 → 형광펜 ▼ → 색 없음. (지우지 않으면 노란색이 인쇄됨)
4. 파일 → 다른 이름으로 저장 → 형식 PDF 로 제출용 PDF를 만든다.
5. Word에서 고친 내용은 HWP·PDF 폴더 파일에는 반영되지 않는다. **이후로는 Word 파일을 원본으로** 삼는다.
6. HWP가 꼭 필요하면 무료 웹 서비스 한컴독스(hancomdocs.com)로 열거나 변환할 수 있다(직접 시험해 보지는 않음). 전자소송은 PDF 제출이 가능하다.

## 반드시 확인할 사항 (주의)

### 1. 아래층 공부상 203호·204호 위치가 반대로 표시되어 있을 수 있음 — 확인 필요
- 평면도에 인쇄된 작은 글씨: **아래 왼쪽 = "203호~503호", 아래 오른쪽 = "204호~504호"**
- 사진 1(공부상 호실 표시)의 파란 글씨: **왼쪽 204호, 오른쪽 203호** → 도면 글씨와 반대
- 우리 방(빨간색 = 도면 표기 "202호~502호")은 도면 글씨와 일치하므로 **목적물 동일성에는 영향 없음**
- 그러나 법원·임대인이 보면 사진 신빙성을 문제 삼을 수 있어, 별지 2 대응표는 "공부상 203호, 204호 → 현장 204호~207호"로만 적어 둠
- 보충서 3항 "공부상 203호에 임차권등기한 다른 임차인이 현장 205호를 사용"과도 연결됨
  - 도면 글씨대로면 공부상 203호 = 아래 왼쪽 → 현장 206·207호 쪽
  - 사진 1 표시대로면 공부상 203호 = 아래 오른쪽 → 현장 204·205호 쪽
- 건축물대장 현황도·등기부로 어느 쪽이 맞는지 확인한 뒤 사진 1 표시와 보충서를 맞춰 고칠 것

### 2. 미납액 40,000원 차이
- 처음 파악한 미납 총액 1,200,000원 ≠ 항목별 합계 1,240,000원(차임 230,000×4 = 920,000 + 관리비 80,000×4 = 320,000)
- 해지 효력에는 영향 없음: 차임만으로 920,000원 > 2기 차임액 460,000원
- 월별 내역으로 확정해 신청서·정산서 금액을 맞출 것. 관리비 공제가 인정되지 않으면 반환잔액은 4,080,000원

### 3. 목적물 표시
- 모든 서류에서 "공부상 나동 제202호 전유부분 전체(현장 표시 제203호)"로 통일. "203호"만 쓰거나 "202호 일부"로 쓰지 말 것
- **경매(2026타경○○)에 낸 보정서에 "202호 일부"로 적혀 있으면 경매법원에도 "202호 전체"로 다시 보정할 것**
- 「일부」·「사선」 표시가 있는 예전 도면은 쓰지 말 것
- 목적물이 전유부분 전체이므로 도면은 법정 필수서류는 아님(일부 임차일 때만 필수). 호실 불일치 소명을 위해 첨부함

### 4. 별지 2 도면·사진
- 치수(가로 3,600mm × 세로 5,700mm)는 사진 속 도면 숫자를 읽은 벽 중심선 기준값. **면적은 반드시 등기부 전유면적을 옮겨 적고**, 도면 치수로 계산하지 말 것
- 사진이라 약간 기울고 작은 글씨가 흐림. 가능하면 정식 발급한 건축물현황도에 같은 빨간 선을 그려 교체
- 사진 속 도면이 설계도면인지 대장과 함께 발급된 현황도인지 사진만으로는 알 수 없음 → 별지 2 "도면 출처"를 확인 후 채울 것

### 5. 임차권등기의 효과와 한계
- **등기부에 임차권등기가 기입된 것을 확인하기 전에는 이사·전출하지 말 것** (먼저 전출하면 종전 대항력이 사라지고 등기 시점부터 새로 시작)
- 2026. 4. 경매개시결정 이후의 임차권등기는 **낙찰자에게 인수되지 않음** → 경매에서는 배당요구가 핵심
- **2026타경○○ 배당요구는 절대 철회하지 말 것**, 배당기일 확인
- 2017년 근저당권보다 앞설 수 없음 → 배당 때 소액임차인 최우선변제(주택임대차보호법 제8조)를 따로 주장
- 등기부상 소유자가 이미 제3자로 바뀌었으면 피신청인과 전략이 달라짐
- 임대인의 이의신청에 대비해 등기 완료 때까지 대화는 문자·녹음으로 남길 것
- 신청 비용은 임대인에게 청구 가능(같은 법 제3조의3 제8항)

### 6. 기타
- 가족이 대신 접수할 때는 위임장(서류 10)과 가족관계증명서를 쓰되, 법원 허가(소송대리허가) 필요 여부를 민사신청과에 먼저 확인
- 이 서류는 검토용 초안이며 법률 자문이 아님. 접수 전 법원 민사신청과(또는 법률구조공단 132)에 확인 권장
